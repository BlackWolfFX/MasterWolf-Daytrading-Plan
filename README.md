# MasterWolf-Daytrading-Plan

Application web interactive pour le plan de trading et checklist ICT (Inner Circle Trader) — **THE MASTERWOLF ICT PLAN**.

## 🚀 Fonctionnalités

- **Plan du Jour** : Checklist pré-session, filtres d'abstention, biais directionnel et validation de setup.
- **Macro & Rituels** : Horaires des Killzones (Asie, Londres, New York), alertes de volatilité et annonces économiques.
- **PD Array** : Identification et cartographie des matrices Premium/Discount, FVG, Order Blocks, Liquidity Pools.
- **Modèles & Risk** : Calculateur de taille de position, règles de risk management strictes et modèles d'entrée ICT.
- **Saisonnalité** : Tendances et cycles saisonniers multi-actifs.
- **Journal & Statistiques** : Suivi des trades, calcul du winrate, du Risk-Reward ratio et métriques de performance.

## 🛠️ Technologies

- HTML5 / CSS3 / JavaScript moderne (Vanilla)
- Mode Sombre / Clair dynamique
- Stockage local (LocalStorage)
